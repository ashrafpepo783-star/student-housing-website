# Student Housing Website

## تشغيل الموقع
1. ثبت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفذ:
   npm install
4. انسخ `.env.example` إلى `.env` وعدّل:
   - SESSION_SECRET
   - ADMIN_PASSWORD
   - SMTP_USER / SMTP_PASS إذا أردت إرسال الإيميلات.
5. شغل:
   npm start
6. افتح:
   http://localhost:3000

## قواعد الحساب
إذا كان إيجار السرير = R:
- التأمين = R
- العمولة = R × 25%
- الإجمالي = R + R + (R × 25%) = 2.25R

مثال 1700:
- إيجار 1700
- تأمين 1700
- عمولة 425
- الإجمالي 3825 جنيه

## مهم
- لا تضع كلمة مرور Gmail الأساسية في الموقع. استخدم App Password.
- قبل نشر الموقع للعامة، استخدم HTTPS، وغيّر SESSION_SECRET وكلمة مرور الإدارة.
- الصور والفيديو حاليًا تُحفظ محليًا داخل `uploads`. للاستضافة الحقيقية يفضّل استخدام تخزين سحابي.
